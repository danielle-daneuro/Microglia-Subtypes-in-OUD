# Microglia Subtypes in OUD

## Project Overview
The original analysis of this dataset analyzed microglia as a single cluster relative to other cell types, uncovering key altered pathways and regulators in OUD, and OUD-sex interactions. This approach, however, could obscure functionally distinct microglia subtypes–which the present project aims to investigate. By first isolating and subclustering microglia, and then performing differential expression, gene set enrichment, and transcription factor analyses, this project aims to identify microglia sub-populations associated with OUD pathology and with OUD-sex interactions, and investigate implicated pathways. 

## Dataset
 Post-mortem dorsal striatum snRNA-seq (Phan et al., 2024); 
 - N = 12 sex and roughly age matched individuals (3 male, 3 female per condition); 
 - 22 biological replicates (12 individuals x caudate and putamen - 2 caudates eliminated from downstream analysis due to wetting failures);
 - ~100k nuclei
